1开通门店钱包

路径：购机通 → 我的 → 门店钱包
← 左右滑动查看步骤 →
第1步
点击【去开通】
进入我的 → 门店钱包，未开通的门店先开通，开通后可长期用于铺货订单支付
第2步
实名认证
输入公司名称、统一社会信用代码、法人姓名等，点击【确认实名校验】
第3步
填写账户信息
输入法人信息、银行账户、银行卡号、开户银行、银行联号、手机号，点击【获取打款金额】
第4步
绑定完成
输入小额到账金额 + 短信验证码，点击【绑定】即完成钱包开通
注意事项：① 企业账户仅支持对公账户；个体工商户可选对公或个人账户。② 充值需使用绑定的银行卡向指定账户转账。

2支付铺货订单

路径：购机通 → 我的 → 铺货订单
← 左右滑动查看步骤 →
第1步
查看订单
在铺货订单中找到待付款订单，点击【去支付】
第2步
选择并支付
选择需要支付的订单商品（可全选），点击【去支付】完成支付

3铺货订单收货

路径：购机通 → 我的 → 铺货订单
← 左右滑动查看步骤 →
第1步
找到待收货订单
在铺货订单中找到待收货订单，点击【一键收货】
第2步
确认收货
点击【确定】按钮，完成收货
收货后可继续处理销售订单发货（见第6步）

4门店钱包充值

路径：购机通 → 我的 → 门店钱包
← 左右滑动查看步骤 →
第1步
点击【充值】
点击【充值】按钮，按提示使用绑定的银行卡向指定账户打款，等待充值完成

5门店钱包提现

路径：购机通 → 我的 → 门店钱包
← 左右滑动查看步骤 →
第1步
点击【提现】并提交
点击【提现】→ 填写提现金额（可全部提现）→ 点击【提交】，等待提现完成
提示：当前提现不收取手续费，仅可提现到绑定银行卡；银行卡冻结则提现失效；可在"我的银行卡"添加多张银行卡后提现（限非充值部分）。

6销售订单发货（快递）

路径：购机通 → 我的订单 → 待发货
← 左右滑动查看步骤 →
第1步
找到待发货订单
消费者下单后，在我的订单 → 待发货中找到对应订单
第2步
提交SN码
填写69码（实物须一致）+ SN码 + IMEI1 + IMEI2，按提示完成快递发货
第3步
等待收货
消费者确认收货（或系统自动收货）后，订单完成
注意：铺货商品快递发货流程与门店自有商品相同，门店获利以预计赚形式计算利润；销售订单完成后请去聚水潭审单完成发货。

7确认收货（录入串码）

路径：购机通 → 我的 → 铺货订单
← 左右滑动查看步骤 →
第1步
点击【确认收货】
在铺货订单列表中找到发货商品，核对商品规格一致后点击【确认收货】
第2步
录入串码
录入商品串码后点击【确定】（支持手动输入或扫码自动录入）
提醒：省分需提前告知门店是录入SN还是录入IMEI1。

8销售流程总览

线上 & 到店两种销售场景
← 左右滑动查看步骤 →
全流程
销售场景流程
线上：门店微信转发商品链接引导下单 → 完成业绩核算。
到店：客户进店扫码 → 选品 → 下单 → 支付 → 商家派单及核销返利。
业务背景 开通服务 商品发布 消费者下单 门店发货 货款结算 退换货 视频教程

📌 门店自身货，也能在平台上销售

门店盘点店内货品即可上架，消费者可直接走门店货源，帮助门店处理品牌压货、减少库存压力，平台也减少缺货流失。

① 门店入驻无仓，成为供应商② 一般纳税人，可开13%发票③ 同意先票后款

!业务痛点

平台缺货：消费者问询时部分商品没上架，门店有货也只能流失商机。

门店压货：品牌压货时门店希望先走压货商品，减少库存压力。

门店现货模式 = 把门店的货"上翻"到平台销售，实现双赢。

1开通门店现货服务

关键步骤：【购机通门店入驻】+【开通门店现货服务】+【完成绑卡】

1
入驻【购机通】
务必选择企业入驻并完成门店审核（主体须企业级 + 一般纳税人资质）
① 入驻购机通（选企业）
2
审核通过，点击【去开通】
位置：我的 → 现货出售 → 去开通
② 去开通
3
点击【立即开通】
模式：顾客购买 → 门店出货 → 生成结算单 → 上传发票 → 平台回款 → 签电子合同
③ 立即开通
4
开通钱包
填写银行账户、银行卡号、开户银行、银行联号等
④ 开通钱包
5
小额打款 + 验证码
回填小额到账金额 + 短信验证码，点击【绑定】
⑤ 小额打款 → 绑定
6
开通完成
可自主发布现货商品；底部有待出售 / 待开票 / 待结算 / 合同签署选项卡
⑥ 开通完成
老客户：仅需开通门店现货服务即可，无需重复入驻。

2商品发布

关键要点：【选品】+【维护零售价】+【配送方式】

1
点击【立即发布】
① 立即发布
2
选择需发布的商品
② 选择商品
3
录入价格 + 库存 + 配送方式
可开启参与本地国补；配送方式至少支持一种：到店自提 / 快递发货；售后由门店自行承担
③ 价格 + 库存
③ 配送方式
4
发布成功
可直接分享二维码给消费者下单
④ 发布成功 · 扫码下单
5
前台已有外展
消费者也可在前台搜索下单（48小时内发货）
⑤ 前台外展
价格规则：门店只需维护【零售价】；平台服务费 = 零售价 × 5%（点位以省分规定为准）。
售后兜底：成交货源为门店时，售后方为门店。

5货款结算 · 每个商品赚多少

发布时即可知晓每单收入。示例：零售价 2699 元 → 国补价 2294.15 元 → 门店预计收入 2564 元 → 平台服务费 135 元。

发布时收入预览
规则：门店录入零售价即可，平台服务费按零售价 × 5%自动算出；押金（可退）= 国补订单质押国补款 × 10%，待国补回款后退还。

8等待财务排款

操作动作：

① 【待开票】查看货款结算单金额，开具发票并上传

② 上传发票后，结算方才可回款

③ 每月 11号、21号、26号根据已结算订单生成电子采销合同，须签署

回款时效（T 工作日）：
① T 日 10:00 前上传发票 → T+1 回款（不含节假日）
② T 日 10:00 后上传发票 → T+2 回款（不含节假日）

!逆向订单流程（退换货）

门店需要确认是否同意退货并完成退货签收，同意后按工具操作执行。

关键动作：确认同意退货 → 完成退货签收。
关联文档：《门店现货上架--门店版本》可直接转发给门店作为操作指引。
山西关联：快递发货模式 + 门店货；门店分享时选择有门店库存标识的商品链接引导下单；门店自提（门店出货+激活、消费者到店下单+提货）。
