一句话总览：各省公司通过【运营助手-分销管理】把商品批量上架到购机通（相当于在购机通开了区域自营分销店铺），门店在购机通【库存】页下单付款，SG 订单走审单→聚水潭→省仓发货，门店收货确认后系统每月 6/16/26 号出对账单，退换货走 5 步逆向流程，国补订单按券领取-使用-审计-开票结算闭环。
1上架准备
（一）市场助手注册 + 认证 + 开通平安钱包▶
1登录
扫描市场助手小程序二维码，或直接搜索【市场助手】小程序；点击【手机号快速验证】并【授权】手机号（务必使用常用微信且该手机号为微信绑定手机号）。
① 扫描二维码登录
2注册主体
企业 / 个体工商户点击【注册新主体】并录入对应信息（已有主体可直接选择）；填写红框信息、勾选【注册即代表同意】后【确认注册】。
注册新主体 / 选择企业或个体户
3实名认证
点击【我的】-【去开通】→ 填写【统一社会信用代码】【法人姓名】【法人身份证号】→【确认实名核验】。
① 我的 → 去开通 → 实名核验
4开通平安钱包（收款用）
企业：填写【账户名称/银行账户/开户银行/银行联号】→ 获取打款金额 → 回填小额到款金额 + 短信验证码 → 绑定。
个体工商户：可选【个人银行卡（法人）】或【对公账户】，完善信息后绑定。
企业：填写账户信息 + 回填打款金额
个体户：个人银行卡（法人）/ 对公账户
（二）魔狮/分销上架前置条件▶
1开通权限
需要开通【运营助手】-【分销管理（订单助手）】权限，走 90-03 流程申请。
2确认收款主体
各省都有自己的收款主体，需要和财务 BP 确认最终用哪个主体（客户付款后将自动划至对应抬头公司账户）。
3组织选择
省分公司上架统一选择【醒市组织】（买家支付后直接流转待发货，自动归属订单、ERP 店铺）。
4收款主体钱包
各省公司收款主体需开通平安钱包方便收款；货主（上架省分公司主体）未开通钱包时买家无法下单。
2发布产品
（一）批量上架分销商品（魔狮自营分销）▶
1进入发布入口
运营助手 → 分销管理 → 分销活动 → 批量发布活动 → 新增活动；发布渠道选【购机通】。
2下载模板并填写
下载模板 → 按 Excel 中 Sheet2 选择商品和 SKU 名称 → 录入 Sheet1 → 维护好价格、库存、标签；分销价 = 集采入仓含税价，付款方式选【先款后货】，履约策略选【线下发货】。
3上传并上架
上传 Excel → 点击【上架成功】，商品进入【待发布】列表。若下拉列表框里没有收款公司主体：把 Excel 这一列的数据有效性删除，手动输入收款公司主体。
批量发布活动弹窗：下载模板 → 上传文件 → 上架成功
4编辑零售价 + 设置可售区域
批量上架默认【全国】；需在【待发布】中手动调整可售区域（本省）并编辑零售价（零售价需参考官网价，勿超售）。配置完成后【确认发布】，商品即在购机通库存页面上架成功。
分销活动编辑：分销类型/分销区域（全国→本省）/发布
提示：点击发布后显示【发布中】就是已经上架的意思，买家已可在前台可见。
（二）发布后买家可见范围▶
① 默认全部采购商可见（购机通分销渠道不指定分销商，全部门店可见）；
② 限售区域：按省设置可售区域，买家按门店所在城市 → 全省 → 全国的报价逻辑取货；
③ 特殊商品不展示：自由担保、已拆封、激活的、上架的"省内怕查/全国怕查"商品不在购机通库存页面展示；
④ 商品在国补商品库但做不了国补：重新在运营助手上传导入国补商品价格修改表。
3分享给买家
商品发布成功后无需额外"分享"动作——门店在购机通小程序【库存】页面即可看到你的商品。

商家推广方式：告诉门店进入购机通小程序 → 点【库存】→ 筛选【个体】→ 在品牌列选择对应品牌 → 找到你的 SKU 下单。

可辅助动作：把具体 SKU/品牌名/价格发给门店，引导其在库存页搜索；如门店未签约（魔狮自营分销），需先引导签约（见下节第 4 步）。

采购商=门店卖家=省公司发货仓=专属省仓
4买家下单
（一）买家下单前准备（3 项缺一不可）▶
1主体身份合规
买家身份需是企业或个体工商户（个人无法下单）。判断方式以门店列表中主体类型为准；能良系货主只做含税业务，个人无法开票所以不能买自营分销的货。
2开通平安钱包并充值
下单必须使用【平安钱包】付款，暂不支持微信、支付宝、云闪付；按需完成钱包充值。
3签署框架合同
在客户 PC 管理后台 https://xswc.xingshiapp.cn/ 完成框架合同签署（签署一次长期有效）。注意：建议用电脑登录签署；若签约后看不到合同，可把公司主体发给 李方晓朱华伟 手动维护。
（二）买家下单路径▶
1进入分销频道
登录购机通 → 进入【库存】页面 → 进入分销频道（未签约的先签约）→ 找到【区采货盘】→ 找到对应的商品。
库存页：筛选【个体】→ 选品牌/SKU → 详情页下单
2下单支付
选 SKU → 选价格 → 选收货地址 → 平安钱包支付（库存不可超售）→ 生成 SG 订单（SG 单号即订单助手原始单号）。下单支付后机器人会在订单群通知，同时扣减购机通库存。
下单后订单群自动通知（含型号/单价/数量/总金额）
注意：库存被扣减归零后商品即不可售，需在运营助手-分销管理-分销活动-发布中-编辑活动，再次同步库存给购机通。
5发货履约
（一）卖家接单发货（运营助手）▶
1查看待发货订单
待发货订单出现在 运营助手 → 分销管理 → 订单管理 → 待发货 列表中，聚水潭同步生成待发货订单。
订单管理-待发货列表
订单详情：订单编号/商品/待发货状态
2审单发货
SG 订单给到审单人员审单至具体省仓发货：在【审单&运营沟通群】中发送聚水潭中对应订单的线上订单号；审单联系 李明叶鲍玉康。各项物流信息、状态自动互相同步。
3业务归属人
业务归属人默认为省总；订单状态在【已收货】之前支持二次编辑，已收货后由日清系统归档，如需调整走日清调整列流程。
订单管理：筛选 + 批量指派给归属人
（二）外部商发货（市场助手渠道）▶
外部商在市场助手渠道（非省分公司主体）上架的订单：在【市场助手】-【我出售的】找到待发货订单 → 点击【发货】→ 选择配送方式（快递发货+单号 / 供货商自配送：送货上门、快递发货两种，买方无需支付快递费）→ 录入串码 → 确认发货。
能良系发货：订单推送聚水潭，请到聚水潭发货。
① 点击发货
② 选择发货方式 + 串码
6确认收货 & 对账
（一）买家确认收货▶
收到货之后，买家在购机通小程序 【我的】-【铺货进货】-【进货订单】 中查看，点击【去收货】完成确认收货。
进货订单 → 去收货
库存模块下单补充：原【进货】模块兼容到【库存】后，仅改变买方下单链路；来源于【市场助手】的订单：卖家收千 2 服务费，买家服务费千 5（目前未收）；【库存】页无平安钱包提示，但仍需在平安钱包充值并使用平安钱包付款。
（二）蓝票对账（卖家收款）▶
1对账周期
系统在每月 6、16、26 号 自动出对账单，对账范围是时间段内已完成收货订单：6 号对上月 21 号至上月末；16 号对当月 1-10 号；26 号对当月 11-20 号。
蓝票账期固定时间
2买家对账
买家需在客户 PC 管理后台 https://xswc.xingshiapp.cn/ 完成对账，并查收发票（我的订单-财务管理-待开票/已开票账单）。
我的订单：待开票账单 / 已开票账单 / 查看订单明细

（二）退换货关键问答▶
问客户退款多久到账？
答今天发起退款，明天才能到账。
问下单有误发起退货退款后，申领的国补券会返回账户吗？
答发起全额退款后，券不会退回账户，但会在七个工作日内恢复领券资格，届时可重新领取。
问客户取消国补单退款，流程怎么走？
答客户购机通点【申请退款】→ 门店后台点【确认收货】→ 等待售后部门询问情况是否退款 → 售后部门操作退款（售后审核找 彭蝶）。
问国补审计显示订单金额大于国补金额怎么办？
答找消费者退货退款，最好先在备案表里确认一下。

（二）国补使用要点▶
问客户付款跳转云闪付没有用到优惠券？
答查看实名是否一致、定位是否开启、APP 是否更新、领的券和活动是否是同一个；打开微信云闪付小程序-我的-我的优惠券查看券详情；若定位问题但手机定位已开，将小程序删除重新进入。
问国补审核图片有什么要求？
答手机：线上国补要求包装 SN + 手机激活 SN + 包装手机激活 SN + 人包装手机，水印带时间+地点+经纬度；线下国补要求包装 SN + 手机激活 SN + 包装手机 SN，水印带时间+地点+经纬度。电脑：背板串码+包装盒串码+开机屏幕显示 SN，水印需带时间+地点+经纬度。图片不符审核不通过 → 编辑替换后提交。
问怎么查看国补商品备案金额？
答商委会发相关的国补商品备案表；表格里没有的在运营助手 → 购机助手 → 国补商品库里查看。国补售价不能超过备案表里的价格。
问国补申请银联上送怎么做？
答线上国补：运营助手 → 购机助手 → 国补申请 → 提交审计 → 输入提交城市 → 编辑（核对实名及激活图片信息，要平台开票后及上传了支付凭证才能提交审计）；线下国补：同上路径，需在云闪付上提交。
问国补发票有什么要求？
答国补只能用于个人消费，公司开给消费者的发票购方抬头只能是个人，不能用公司抬头开。
问做完一单国补后多久结算款项？押金多久退回？
答商家开票后，一般为 T+1/T+2 日结算；国补押金 2-3 个月，政府结算后再退回。大商上传发票后 T+1 回款，10:00 之后上传的 T+2 回款。
问国补分销系统流程问题找谁？
答国补：许信斌　分销：李方晓
9高频问答
问魔狮分销流程是什么？
答后台上传路径：运营助手 → 分销管理 → 分销活动 → 批量发布活动 → 新增活动，上传相关表格，在待发布中进行零售价编辑发布；客户下单路径：登录购机通 → 进入【库存】页面 → 进入分销频道（没签约的先签约）→ 找到区采货盘 → 找到对应的商品。
问魔狮个人可以下单吗？
答货主是能良系，能良只能做含税业务，所以个人不能买自营分销的货（无法开票）；个体工商户 + 企业签约后可以下单。
问魔狮个体工商户下不了单是什么原因？
答可以看看门店的主体类型是企业还是个人，门店主体类型是企业才可以下单。
问魔狮下单提示【货主】未开通钱包？
答【货主】指上架魔狮的省分公司主体，需要开通钱包买家才可以下单；可用上架主体登录购机通，找到钱包按流程开通；如需要钱包材料，联系省分财务 BP 咨询。
问魔狮下单时需要签约，但点击签约看不到合同？
答①已在修复，可先把公司主体发给李方晓、朱华伟手动维护；②让买家用电脑登录 https://xswc.xingshiapp.cn 进行签约。
问魔狮买家下单后怎么发货？
答和之前的分销订单一样，SG 订单给到审单人员审单发货，审单联系李明叶、鲍玉康。
问购机通分销发货审单找谁？
答在【审单&运营沟通群】中发送聚水潭中对应订单的线上订单号。
问魔狮上架需要哪些权限？
答需要开通【运营助手】-【分销管理（订单助手）】权限，走 90-03 申请。
问魔狮上架选能良组织还是醒市组织？
答省分公司上架统一选择【醒市组织】；购机通渠道且是醒市组织的订单，买家支付后直接流转待发货，无需业务侧审核。
问魔狮上架区域选本省怎么设置？
答批量上架时默认选【全国】，选择【新增活动】把模版上传后，手动调整可售区域为本省。
问商家发布商品时发现没有该型号？
答在其他系列里面查询，若无该型号请及时联系品牌运营。
问商家发布商品时显示超过最大金额？
答请按照参考官网零售价，勿超过零售价售卖；若填写零售价仍显示超过最大金额，及时联系品牌运营。
问购机通与市场助手是什么关系？
答市场助手更偏向大订单分销铺货类，购机通包含了市场助手的数据；市场助手做不了国补。
问购机通 SG 单号是什么？
答购机通 SG 单号是订单助手的原始单号。
问能良系门店可以买分销商品吗？
答能良系门店不可购买分销管理上架的分销商品；分销商品的发布渠道不选购机通，商品不会出现在购机通库存页面。
