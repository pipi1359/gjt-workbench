购机通 · 供应商操作指南

依据《购机通-进货》整理 · 持续更新

背景：随国补业务发展已积累约 6 万下沉门店，平台做供需两侧撮合桥梁，提供"商品 + 交易 + 钱包 + 对账 + 进销存"全流程解决方案。2026 年 1 月 8 日起【进货】已兼容到库存模块。
1卖家上架
（一）先进行注册 + 认证▶
1登录（操作端：市场助手小程序）
扫描小程序二维码登录，或直接搜索"市场助手"小程序；点击【手机号快速验证】（务必保证微信是常用微信且该手机号为此微信绑定手机号）；【授权】手机号。
① 扫描二维码登录
② 点击【手机号快速验证】
③ 【授权】手机号
2注册（企业 / 个体工商户 / 个人）
企业或个体工商户：点击【注册新主体】→ 选择【企业/个体工商户】（个人可选【个人】）→ 填写红框信息（公司名称、行业简称、主营品牌、主营地区）→ 勾选《注册即代表同意》→ 【确认注册】。注意：如已有主体可直接选择对应主体。
① 点击【注册新主体】
② 选择【企业/个体工商户】或【个人】
③ 填写红框信息 → 勾选同意 → 确认注册
3实名认证
点击【我的】-【去开通】→ 填写主体对应的【统一社会信用代码】【法人姓名】【法人身份证号】→ 【确认实名核验】。
① 点击【我的】-【去开通】
② 填写信息 → 确认实名核验
4开通平安钱包
企业级客户：填写【账户名称】【银行账户】【开户银行】【银行联号】→ 【获取打款金额】→ 回填【小额到款金额】+【短信验证码】→ 【绑定】。
企业：① 填写账户信息
企业：② 回填打款金额 + 验证码
③ 绑定成功
个体工商户：选择【个体工商户】，可选【个人银行卡（法人）】或【对公账户】，完善信息后点击【绑定】。
个体户：① 个人银行卡（法人）
个体户：② 对公账户
③ 绑定成功
非企业级用户：选择【个人】并录入红框信息注册 → 在【我的】点击【实名认证】完善信息 → 输入小额到款金额与手机号验证码开通平安账户。
非企业：① 个人注册
非企业：② 实名认证
非企业：③ 小额到款开通平安账户
恭喜完成登录和注册环节，快去发布商品～
（二）铺商品▶
1手机端上架（随时随地上传商品）
点击底部【报价】→ 选择商品【发布商品】（可勾选"自由交易"或"醒市担保"）→ 填写价格 / 库存 / 包装 / 激活等信息 → 【确认发布】。发布后可在【我的货架】查看，注意报价时效 2 天，需及时更新报价。
① 点击【报价】
② 发布商品
③ 查看商品（我的货架）
2PC 端批量上架（省时省力）
登录网址：https://market.xingshiapp.cn/profile/shelves/publish（建议使用谷歌浏览器）→ 选择对应上架主体登录 → 选择【醒市担保】→ 点击【下载模板】（按 excel 的 sheet2 选择商品和 SKU 名称，录入到 sheet1，维护好价格 / 库存 / 标签）→ 点击【导入商品】【上传 excel】（单次上限 300 条）。
① 选择【醒市担保】- 下载模板
② 点击下载模板，按 sheet2 选品录入 sheet1
③ 上传 excel（单次上限 300 条）
（三）卖家发货▶
1外部商发货（操作端：市场助手）
在【我出售的】找到待发货订单 → 点击【发货】→ 选择【配送方式】（快递发货 + 快递单号 / 快递公司）+ 录入【串码信息】→ 【确认发货】。
① 点击【发货】
② 选择发货方式 + 串码
③ 确认发货
2能良系发货
订单推送聚水潭，请到聚水潭发货。
2门店进货
（一）门店入驻购机通▶
1入驻流程
扫 BD 码 → 点【新注册】（未注册门店点【注册新主体】）→ 填写【企业信息】（企业 / 个体工商户 / 小微商户(个人)；法人身份证号个体工商户必填）→ 录入【门店信息】（门店名称、所属行业、主营品牌、门店地址、门店电话，可上传门头照片）→ 勾选协议 → 【提交审核】→ 等待审核完成即可外展。
① 扫 BD 码 → 点新注册
② 填写企业信息
③ 录入门店信息 → 提交审核
（二）下单进货▶
1选品
在【购机通】新增一级菜单"进货"（限 B 端门店可见）：左上角【省份】+ 搜索栏 + 分类 tab；商品按"省份 + 分类"展示；点击【筛选】可唤出筛选侧边栏（不同分类对应不同筛选项）。
地址逻辑：左上角地址取门店所在城市 → 该城市无商品则取全省报价 → 全省无报价则取全国。
① 进货页选品（省份 + 分类 + 筛选）
2下单
点击【去下单】→ 选收货地址 → 使用平安账户钱包支付（暂不支持微信、支付宝、云闪付）→ 生成订单；若卖家未录入串码，买家可在确认收货时【上传串码】；配送方式可根据卖家设置。
① 点击【去下单】
② 选地址 + 钱包支付
③ 订单详情 / 上传串码 / 完成
3在库存页面下【进货】订单
详见《如何在【库存】模块下进货订单》。注意：目前在市场助手上架的商品，有些情况下不在【库存】页面展示，需要注意！
3注意事项
  1. 自进货兼容到库存后（2026 年 1 月 8 日），省分公司主体在市场助手上架的订单，通过购机通【库存】页面下单的，在聚水潭会自动创建订单，无需手动创建。
  2. 外部商在市场助手上架的，无需推送到聚水潭。
  3. 发票走线下。
  4. 不支持个人买家下单；本期不支付分店使用总店余额进行下单。
  5. 服务费点位：本期卖家收取千分之 2（千2），买家不收服务费。
4高频疑问解答
问如何避免供应商乱报价、不履约的情况发生？
答 后期版本会上线供应商管控机制（如保证金）。
问通过购机通走市场分销采货，费用是按照市场分销的费用吗？
答 千 2 平台技术服务费，收卖方。
问卖家信息不保密，厂商发现后有处罚风险？
答 请遵守平台规则合规经营。
