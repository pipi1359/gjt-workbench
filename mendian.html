购机通 · 门店铺货操作

门店操作指引 · 省分公司已铺货，门店按下述步骤操作
开通钱包 支付铺货 确认收货 钱包充值 钱包提现 销售发货 录串码收货 销售总览

1开通门店钱包

路径：购机通 → 我的 → 门店钱包
← 左右滑动查看步骤 →
第1步
点击【去开通】
进入我的 → 门店钱包，未开通钱包的门店先开通，开通后可长期用于铺货订单支付
第2步
实名认证
输入公司名称、统一社会信用代码、法人姓名等，点击【确认实名校验】，校验通过即完成实名认证
第3步
填写账户信息
输入法人信息、银行账户、银行卡号、开户银行、银行联号、手机号，点击【获取打款金额】
第4步
绑定完成
输入小额到账金额 + 短信验证码，点击【绑定】即完成钱包开通
注意事项：① 企业账户仅支持对公账户；个体工商户可选对公或个人账户。② 充值需使用绑定的银行卡向指定账户转账。

2支付铺货订单

路径：购机通 → 我的 → 铺货订单
← 左右滑动查看步骤 →
第1步
查看订单
在铺货订单中找到待付款订单，点击【去支付】
第2步
绑定银行卡并支付
选择需要支付的订单商品（可全选），点击【去支付】完成支付

3铺货订单收货

路径：购机通 → 我的 → 铺货订单
← 左右滑动查看步骤 →
第1步
找到待收货订单
在铺货订单中找到待收货订单，点击【一键收货】
第2步
确认收货
点击【确定】按钮，完成收货
收货后可继续处理销售订单发货（见下方第6步）

4门店钱包充值

路径：购机通 → 我的 → 门店钱包
← 左右滑动查看步骤 →
第1步
点击【充值】
点击【充值】按钮，按提示使用绑定的银行卡向指定账户打款，等待充值完成

5门店钱包提现

路径：购机通 → 我的 → 门店钱包
← 左右滑动查看步骤 →
第1步
点击【提现】并提交
点击【提现】→ 填写提现金额（可全部提现）→ 点击【提交】，等待提现完成
提示：当前提现不收取手续费，仅可提现到绑定银行卡；银行卡冻结则提现失效；可在"我的银行卡"添加多张银行卡后提现（限非充值部分）。

6销售订单发货（快递）

路径：购机通 → 我的订单 → 待发货
← 左右滑动查看步骤 →
第1步
找到待发货订单
消费者下单后，在我的订单 → 待发货中找到对应订单
第2步
提交SN码
填写69码（实物须一致）+ SN码 + IMEI1 + IMEI2，按提示完成快递发货
第3步
等待收货
消费者在购机通确认收货（或系统自动收货）后，订单完成
注意：铺货商品快递发货的销售流程与门店自有商品相同，区别在于门店获利以预计赚的形式计算利润；销售订单完成后，请去聚水潭审单完成发货。

7铺货商品确认收货（录入串码）

路径：购机通 → 我的 → 铺货订单
← 左右滑动查看步骤 →
第1步
点击【确认收货】
在铺货订单列表中找到发货商品，核对商品规格一致后点击【确认收货】
第2步
录入串码
录入商品串码后点击【确定】（支持手动输入或扫码自动录入）
提醒：同步门店操作前，省分需提前告知门店是录入SN还是录入IMEI1。
